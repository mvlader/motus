# Подключение openclaw к MOTUS

MOTUS отвечает на `127.0.0.1:18790` **внутри контейнера grach** — обычный
локальный HTTP, `curl` как к любому сервису. (Физически он в отдельном контейнере
`motus`, проброшен сюда Incus-прокси — openclaw это не важно.)

Нужно два вызова. Всё остальное — по желанию.

---

## Вызов 1. Перед каждым ответом модели

```
GET http://127.0.0.1:18790/state/card      (таймаут 2 секунды)
```

Ответ:

```json
{
  "card": { "text": "последний обмен — несколько минут назад; ..." },
  "gate": {
    "regime": "baseline",
    "may_initiate": false,
    "max_tokens": 900,
    "allowed_tools": ["read", "memory", "exec", "write", "net", "outbound"],
    "forbidden": [],
    "context_band": "fresh"
  },
  "tier": 0
}
```

**Что сделать:**

1. `card.text` → вставить **как есть** в самый конец системного промпта.
2. `gate` → ограничить сессию:

| поле | значение | что делать |
|---|---|---|
| `may_initiate` | `false` | не давать модели писать пользователю по своей инициативе |
| `allowed_tools` | список | оставить сессии только эти инструменты, остальные отключить |
| `forbidden` | список меток | не выполнять действия этих типов (`outbound` = отправка, `irreversible` = необратимое, `write`, `net`, `new_topics`, `long_form`, `promises`) |
| `max_tokens` | число | верхний предел длины ответа |
| `regime` | имя | справочно (`baseline` / `SEEKING` / `CARE` / `PLAY` / `FEAR` / `RAGE` / `PANIC`) |

**Если не ответил за 2 секунды или ошибка** → собрать промпт без карточки, ничего
не ограничивать. MOTUS не должен ронять бота.

---

## Вызов 2. После каждого сообщения пользователя

```
POST http://127.0.0.1:18790/event      (таймаут 2 секунды)
тело:  {"kind": "user_message", "payload": {"text": "<текст сообщения пользователя>"}}
```

Ответ разбирать не нужно. Ошибку игнорировать.

MOTUS оценит текст своим словарём (~1 мс) и **сразу его выбросит** — хранит только
6 чисел, не содержание сообщения.

---

## Порядок внедрения (по шагам)

1. **Сделать только Вызов 1 (вставку `card.text`) и Вызов 2.** `gate` пока НЕ
   применять — просто пусть карточка появляется в промпте, а сообщения уходят в MOTUS.
2. Пару дней смотреть журнал:
   ```bash
   incus exec motus -- curl -s --unix-socket /run/motusd/adm.sock 'http://x/journal/tail?n=30'
   ```
   Убедиться: после эмоциональных сообщений драйвы в записях `tick`/`impulse`
   двигаются осмысленно (благодарность → CARE вверх, «застрял» → RAGE, и т.п.).
3. **Включить применение `gate`** (таблица выше). Вот теперь MOTUS реально
   ограничивает бота, а не просто подсказывает.

---

## Необязательные события

Слать в тот же `POST /event`, когда происходит:

| Что случилось | тело |
|---|---|
| инструмент упал | `{"kind":"tool_error","payload":{"tool":"имя","blocking":true}}` |
| пропала сеть | `{"kind":"net_down"}` |
| сеть вернулась | `{"kind":"net_up"}` |
| бот ответил (двигает часы контекста) | `{"kind":"assistant_message"}` |

## Позже: фоновые задачи

Когда драйв накапливается, MOTUS может выдать задачу:

```
GET http://127.0.0.1:18790/task/next   →   {"task": {"template_id": "...", ...} | null, "tier": 1}
```

Задачу выполнить **без единой отправки пользователю**, потом отчитаться:

```
POST http://127.0.0.1:18790/consummation
тело:  {"template_id": "<из задачи>", "verified": true}
```

Без этого драйвы SEEKING / CARE / PLAY гасить нечем, кроме разговора. Исполнителя
задач в openclaw пока нет — это отдельная работа.

---

## Что openclaw НЕ видит (и не должен)

`GET /state/raw`, журнал, `/tick`, `/sleep` → **404**. Числа драйвов, код MOTUS,
файл состояния — в другом контейнере, недоступны. Так задумано: модель не видит
чисел, только текст карточки.

Оператору (тебе) полное состояние — так:
```bash
incus exec motus -- curl -s --unix-socket /run/motusd/adm.sock http://x/state/raw | python3 -m json.tool
```

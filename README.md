# MOTUS

Слой мотивации и поведенческого управления для бота на stateless-LLM.
Числовые шкалы потребностей и систем действия по Панксеппу, жёсткие логические шлюзы,
фоновый heartbeat и явная модель времени.

**Это не система памяти и не система идентичности.** MOTUS ортогонален им: он отвечает
на вопросы «чего система сейчас хочет» и «что ей сейчас разрешено», а не «что она
помнит» и «кто она». С Anima-подобным слоем памяти стыкуется в двух швах: общая ось
времени и (опционально) аффективный тег на записях.

## Инвариант

> Числа никогда не покидают код. Модель никогда не видит чисел состояния.

Модель получает только текстовую карточку фиксированного лексикона и выбирает
формулировки. Ни одной цифры — проверяется тестом `test_no_digits_ever`.

```
последний обмен — несколько часов назад; нить разговора уже подостыла — уточняй,
если ссылаешься на неё. Состояние: тянет разобраться в чём-то новом.
Можно предложить тему самому — одну, не список.
```

## Запуск

```bash
python3 -m motus.daemon --port 18790
```

```bash
curl -s localhost:18790/state/card | python3 -m json.tool
```

Зависимостей нет — только стандартная библиотека Python 3.11+. Это осознанно:
система должна переживать `pip` на Raspberry Pi и запускаться из systemd без venv.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

## Калибровка

```bash
python3 tools/simulate.py --hours 72 --scenario silence
```

Параметров около сорока; вслепую их не настроить. Реплей-стенд прогоняет сутки за
миллисекунды — калибруй по графикам, а не подбором.

## Что уже работает (v0.1)

- L0 гомеостат: 6 драйвов, 3 модулятора, сома, три часа
- L1 гейткиперы: гистерезис, время удержания, приоритет, маска разрешений
- L2 генератор карточки: фиксированный словарь, бюджет, запрет цифр
- L-1 оценщик сигнала: правила событий + оценка текста словарём (детерминированно,
  `mode: lexical`). Режим `model` (малая локальная модель через llama.cpp) собран
  и проверен, но не по умолчанию — [docs/04-model-l1.md](docs/04-model-l1.md)
- Бюджет инициаций, рефрактерность, штраф за молчание
- Репертуар задач и учёт эффективности
- Журнал append-only и реплей с проверкой детерминизма
- Демон с HTTP-интерфейсом
- Датчик железа Pi 5: `deploy/somatic_probe.py` + systemd-таймер шлют температуру,
  троттлинг, свободный диск и живость openclaw в `somatic_update()`
- 63 теста, включая поведенческий критерий «при закрытом гейте инициаций ноль»

## Чего ещё нет

- **Исполнитель задач** — набор задач выбирает задачу, но никто её не выполняет.
  Нужен адаптер к openclaw.
- **Курирование репертуара моделью** (шаг 2 ночного цикла). `maybe_sleep()` собирает
  отчёт об эффективности, но не даёт модели его переписать.
- **Новизна через эмбеддинги** — критерий консумации SEEKING описан в формулах,
  но требует локального эмбеддера (или, по примеру L-1, детерминированной замены).
- **Аффективный тег на записях памяти** — решение отложено намеренно.
- **Пост-проверка ответа модели** — пятое анти-дрейфовое правило: дешёвый чек
  «нарушены ли директивы» с регенерацией при нарушении. Без него состояние
  влияет на промпт, но не проверяется на выходе.
- **Фильтр на запись в память** — правило 2 ниже пока действует как соглашение,
  а не как код: ничто технически не мешает записать «мне было тревожно» в
  дневной файл.
- **Субъективное время** (`Δt_subj = Δt·(1 + k·A)`) — описано в формулах §1.3,
  в коде и конфиге отсутствует.

## Граница самомодификации

| Уровень | Кто правит |
|---|---|
| Ядро драйва: определение, критерий насыщения | никто, константа в коде |
| Математика: гейны, пороги, τ, эффективность | только код, по измерениям |
| Репертуар: шаблоны, формулировки, rationale | модель, ночью, в пределах квоты |

Какой драйв доминирует — решает математика. Какую задачу взять внутри драйва —
решает модель.

## Два правила, которые нельзя нарушать

1. **Фоновая задача не отправляет ничего наружу.** Никогда. Единственный путь к
   исходящему сообщению — Tier 2 с открытым `may_initiate`. Иначе гейты обходятся
   через репертуар, и вся конструкция бессмысленна.
2. **Вывод генератора карточки не попадает в память как текст.** Если бот запишет
   «мне было тревожно», в следующей сессии это приедет в стартовый контекст как факт
   о себе и будет отыгрываться поверх математики — неконтролируемый контур,
   обходящий ядро, с задержкой в сутки.
